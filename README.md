# 전기요금 계산기

전력 사용량(kWh)을 입력하면 학습용 예시 단가를 적용해 예상 전기요금을 계산하는 웹 프로그램입니다. 

## 주요 기능
- 전력 사용량 입력 및 예상 요금 계산
- 사용량 구간에 따른 단가 적용
- 여러 번 계산한 기록 표시
- 계산 기록 삭제
- 잘못된 입력에 대한 안내 메시지
- PC와 스마트폰 화면에 맞춘 반응형 디자인

## 사용 방법
1. 웹사이트에 접속합니다.
2. 전력 사용량(kWh)을 입력합니다. 예: `150`
3. **요금 계산하기** 버튼을 누릅니다.
4. 예상 요금과 계산 기록을 확인합니다.
5. **기록 삭제** 버튼으로 기록을 지울 수 있습니다.

## 계산 기준
- 200kWh 이하: 120원/kWh
- 200kWh 초과 ~ 400kWh 이하: 180원/kWh
- 400kWh 초과: 250원/kWh
- 기본요금: 1,000원

> 이 프로그램은 과제를 위한 학습용 예시입니다. 실제 한국전력 전기요금과 다를 수 있습니다.

## GitHub Pages 배포
1. GitHub에서 새 Public 저장소를 만듭니다.
2. 저장소 최상위(root)에 `index.html`과 `README.md`를 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 Source를 `Deploy from a branch`로 선택합니다.
5. Branch는 `main`, Folder는 `/ (root)`로 선택하고 **Save**를 누릅니다.
6. 배포가 완료되면 Pages 화면에 표시되는 `https://계정이름.github.io/저장소이름/` 주소로 접속합니다.
